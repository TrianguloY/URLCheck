Cette application agit comme étape intermédiaire avant l'ouverture de liens URL. Lorsque vous cliquez sur un lien et choisissez cette application, une boîte de dialogue affiche des informations sur le lien. Particulièrement utile pour ouvrir un lien externe depuis un e-mail, un réseau social ou similaire.

Développée pour un usage personnel mais librement partageable, elle est gratuite, sans publicité, légère et utilise le minimum d'autorisations (uniquement l'accès Internet pour les vérifications demandées par l'utilisateur). Code source sur GitHub pour suggérer ou apporter des modifications : https://github.com/TrianguloY/URLCheck

Structure modulaire (vous pouvez activer, désactiver et réorganiser les modules) :

* Texte Saisie : affiche l'URL actuelle, modifiable manuellement. Ne peut être désactivé.
* Historique : affiche et annule toute modification des modules ou de l'utilisateur (annuler/rétablir).
* Registre : conserve un registre des URL vérifiées (afficher, modifier, copier, effacer...).
* Code d'état : effectue une requête sur l'URL et affiche le code d'état (OK, erreur serveur, introuvable...). En cas de redirection, appuyez sur le message pour vérifier la nouvelle URL. L'URL n'est pas évaluée, donc les redirections JavaScript ne sont pas détectées.
* Analyseur d'URL : analyse l'URL via VirusTotal et affiche le rapport. Nécessite une clé API personnelle gratuite VirusTotal. VirusTotal™ est une marque commerciale de Google, Inc.
* Nettoyeur d'URL : utilise la base ClearURLs pour supprimer les paramètres inutiles et d'affiliation, et gère les redirections hors ligne courantes. Base : https://docs.clearurls.xyz/latest/specs/rules/
* Déraccourcisseur : utilise le service https://unshorten.me/ pour déraccourcir les URL.
* Suppresseur de requêtes : affiche les paramètres d'URL décodés pour les supprimer ou les vérifier.
* Analyseur de style : vérifie l'URL avec des expressions régulières (regex) pour avertir, suggérer ou appliquer des remplacements. Modèles modifiables et personnalisables.
  - Avertit en cas de caractères non-ASCII (ex. lettres grecques) utilisés pour l'hameçonnage : googĺe.com au lieu de google.com.
  - Suggère de remplacer http par https.
  - Suggère des alternatives respectueuses de la vie privée pour YouTube, Reddit ou Twitter [désactivé par défaut].
* Vérificateur d'hôtes : étiquette les hôtes manuellement ou via un fichier hosts distant pour avertir des sites dangereux ou spéciaux. Inclut les fichiers hosts de StevenBlack (adware/malware, fakenews, jeux, contenu adulte) : https://github.com/StevenBlack/hosts.
* Module de débogage : affiche l'URI d'intention et éventuellement les infos du service ctabs (onglets personnalisés). Destiné aux développeurs.
* Module d'ouverture : boutons d'ouverture et de partage. Si plusieurs applications peuvent ouvrir le lien, une flèche permet de choisir. Ne peut être désactivé.
