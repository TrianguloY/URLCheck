URL இணைப்புகளைத் திறக்கும்போது இந்தப் பயன்பாடு ஒரு இடைத்தரகராகச் செயல்படுகிறது. URL தகவல்களைக் கொண்ட சாளரம் காட்டப்பட்டு, அதை மாற்ற அனுமதிக்கிறது. மின்னஞ்சல், சமூக வலைப்பின்னல் போன்றவற்றிலிருந்து வெளிப்புற இணைப்பைத் திறக்கும்போது மிகவும் பயனுள்ளது.

URLCheck, TrianguloY ஆல் உருவாக்கப்பட்ட திறந்த மூல (CC BY 4.0) இலவச பயன்பாடாகும்; விளம்பரங்கள் அல்லது டிராக்கர்கள் இல்லை, லேசானது, குறைந்த அனுமதிகளையே பயன்படுத்துகிறது (பயனர் கோரும்போது மட்டும் இணைய அனுமதி). மூலக் குறியீடு GitHub இல் உள்ளது: https://github.com/TrianguloY/URLCheck

தொகுதி அமைப்பு (தொகுதிகளை இயக்க/முடக்க மற்றும் மறுவரிசைப்படுத்தலாம்):

* உள்ளீட்டு உரை: கைமுறையாகத் திருத்தக்கூடிய தற்போதைய URL ஐக் காட்டும். முடக்க முடியாது.
* வரலாறு: பிற தொகுதிகள் மற்றும் பயனர் திருத்தங்களைப் பார்த்து மாற்றியமைக்கும் (செயல்தவிர்/மீண்டும் செய்).
* பதிவு: சரிபார்க்கப்பட்ட URLகளின் பதிவை வைத்திருக்கும் (பார்க்க, திருத்த, நகலெடுக்க, அழிக்க...).
* நிலை குறியீடு: பொத்தானை அழுத்தினால் நெட்வொர்க் கோரிக்கை மூலம் நிலை குறியீடு காட்டப்படும் (சரி, சர்வர் பிழை, கிடைக்கவில்லை...). திசைதிருப்பல் இருந்தால் புதிய URL ஐச் சரிபார்க்கலாம். JavaScript திசைதிருப்பல்கள் கண்டறியப்படாது.
* URL ஸ்கேனர்: VirusTotal மூலம் URL ஐ ஸ்கேன் செய்து அறிக்கையைக் காட்டும் (இலவச VirusTotal API விசை தேவை). VirusTotal™ என்பது Google, Inc. இன் வர்த்தக முத்திரை.
* Url Cleaner: ClearURLs பட்டியலைப் பயன்படுத்தி பயனற்ற அளவுருக்களை நீக்கும்; பொதுவான ஆஃப்லைன் திசைதிருப்பல்களையும் கையாளும். பட்டியல்: https://docs.clearurls.xyz/latest/specs/rules/
* சுருக்கப்படாதது: URLகளைத் தொலைவிலிருந்து விரிவாக்க https://unshorten.me/ ஐப் பயன்படுத்துகிறது.
* வினவல் நீக்கி: டிகோட் செய்யப்பட்ட URL வினவல்களைக் காட்டி நீக்க அல்லது சரிபார்க்க உதவும்.
* வடிவ தொகுதி: regex வடிவங்களுடன் URL ஐச் சரிபார்த்து எச்சரிக்கும், பரிந்துரைக்கும் அல்லது மாற்றும். சொந்த வடிவங்களையும் உருவாக்கலாம்.
  - ASCII அல்லாத எழுத்துக்களுக்கு எச்சரிக்கை (ஃபிஷிங்: googĺe.com vs google.com).
  - 'http' ஐ 'https' ஆக மாற்றப் பரிந்துரை.
  - YouTube, Reddit, Twitter க்கு தனியுரிமை மாற்றுகள் [இயல்புநிலையாக முடக்கப்பட்டுள்ளது].
* ஹோஸ்ட்கள் சரிபார்ப்பு: கைமுறையாகவோ தொலை ஹோஸ்ட்கள் கோப்பு மூலமோ ஹோஸ்ட்களை லேபிள் செய்து ஆபத்தான தளங்களை எச்சரிக்கும். StevenBlack ஹோஸ்ட்கள் (adware/malware, fakenews, gambling, வயது வந்தோர் உள்ளடக்கம்): https://github.com/StevenBlack/hosts.
* பிழைத்திருத்த தொகுதி: intent uri மற்றும் ctabs (custom tabs) தகவல்களைக் காட்டும் (டெவலப்பர்களுக்கானது).
* திறந்த தொகுதி: திற மற்றும் பகிர் பொத்தான்கள். பல பயன்பாடுகள் இருந்தால் தேர்வு செய்ய அம்புக்குறி காட்டப்படும். முடக்க முடியாது.
