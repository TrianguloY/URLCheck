# Work thread reports

One file per work thread. Each file must contain: purpose and scope, what was examined, what was done (with PR/issue links and commit SHAs), decisions and the reasons, things skipped and why, open questions for the owner, and lessons for next time. No secrets, tokens, webhook URLs or personal settings values.
